Privacy Policy — CampUncharted Studio

Last updated: November 2026

1. Purpose & Scope

CampUncharted Studio is a private single-owner publishing automation tool used exclusively by the owner of the @CampUncharted YouTube channel to upload videos, attach captions and thumbnails, and read channel-owned analytics.

2. Google & YouTube API Data

This application requests YouTube Data API v3 and YouTube Analytics API access solely for the channel owner's own authorized account. It does not accept third-party public user logins, does not collect personal information from visitors, and does not sell or share any Google user data with third parties.

3. Data Storage & Security

OAuth credentials are stored strictly inside encrypted repository secrets and are never exposed in public source code or logs. Only aggregate, non-personal video performance metrics (such as view counts and average view percentage) are stored for scheduling optimization.

4. Revoking Access

The channel owner may revoke API permissions at any time from Google Account Permissions.
